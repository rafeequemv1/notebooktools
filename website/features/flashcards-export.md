## Export NotebookLM flashcards and quizzes

NotebookLM makes good flashcards and quizzes from your sources, but keeps them inside NotebookLM. NotebookTools sends them where you study and teach: flashcards to **Anki** or **Quizlet**, quizzes to **Kahoot**, **Wayground (Quizizz)** or **Moodle**, any set to CSV or Markdown, and printable fold-over cards or a quiz worksheet with an answer key. It reads the cards and questions exactly as NotebookLM made them, including each answer's explanation, and runs in your browser.

### How to use it

1. In a NotebookLM notebook, create flashcards or a quiz in the Studio panel.
2. Click **Flashcards** in the NotebookTools ribbon (in the Studio group). The notebook's decks and quizzes are listed with their card or question counts.
3. Pick a set, then a format. Flashcards: Anki, Quizlet, CSV, Markdown, Print or PDF. Quizzes: Kahoot, Wayground, Moodle, Anki, CSV, Print or PDF.
4. Import the file: in Anki, File → Import; in Quizlet, Create → Import and paste; in Kahoot, Add question → Import spreadsheet; in Wayground, Import from spreadsheet; in Moodle, Question bank → Import → GIFT.
5. In the notebooks hub, the Studio tab has an **Export** button on every flashcard deck and quiz too.

### Why it helps

Spaced repetition in Anki, a class game in Kahoot or a graded quiz in Moodle all start from questions you already have in NotebookLM. Retyping them takes longer than making them. With an export, a deck of 40 cards or a 20-question quiz goes to the app you use in a few seconds, with the correct answers marked and the explanations kept.

## Flashcards and quizzes export: frequently asked questions

### Can I export NotebookLM flashcards to Anki?

Yes. Choose Anki and NotebookTools saves a text file with the deck name and card fields set up; in Anki, choose File → Import and pick it. Line breaks and formatting in the answers are kept.

### Can I put a NotebookLM quiz into Kahoot or Wayground?

Yes. Choose Kahoot or Wayground (Quizizz) for a spreadsheet in that app's import layout, with the correct answers marked. Kahoot allows four answers and short text, so longer questions are shortened and you are told how many.

### What about Quizlet?

Quizlet imports by pasting. Choose Quizlet and the cards are copied with a tab between term and definition; in Quizlet, choose Create → Import and paste.
