## A NotebookLM prompt library inside the chat box

NotebookTools adds a prompt library to NotebookLM. Type **/** in the chat box and a menu shows your saved prompts first, then ready-made slide deck templates. Pick one and the full prompt is inserted, ready to edit or send.

### How to use it

1. Open a notebook in NotebookLM.
2. Type **/** in the chat box to open the prompt menu.
3. Keep typing to filter, use ↑ ↓ to move and Enter to choose.
4. Edit the inserted prompt if you need to, then send it.
5. Add, edit or delete your own prompts in the side panel's **Prompts** tab.

### Why it helps

Good NotebookLM output depends on a precise prompt: the audience, the format, the length and what to cite. Retyping a long study-guide or slide prompt in every notebook is slow, and the wording that worked gets lost. Saved prompts keep that wording one keystroke away, and the slide templates give you deck styles to start from instead of a blank box. Your saved prompts work in every notebook, so a prompt you refine for one project is ready for the next.

## Prompt library: frequently asked questions

### How do I use slash commands in NotebookLM?

Install NotebookTools, open a notebook and type / in the chat box. A menu lists your saved prompts and slide templates; pick one with the arrow keys and Enter to insert it.

### Can I save my own NotebookLM prompts?

Yes. Add them in the Prompts tab of the NotebookTools side panel. They appear at the top of the / menu in every notebook.
