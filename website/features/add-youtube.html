How it works

From install to done

  1. 1
    Open a YouTube video

    Watch any video or playlist in Chrome with NotebookTools installed.

  2. 2
    Click Add to NotebookLM

    The button sits on the watch page next to the player.

  3. 3
    Pick a notebook

    Search existing notebooks or create a new one — demo shows the picker.

  4. 4
    Source appears in NotebookLM

    The YouTube URL is added as a source in the left Sources panel.
