## Run several NotebookLM prompts one after another

The NotebookTools prompt queue lines up prompts for a NotebookLM notebook and sends them for you, one at a time. Each prompt goes into the chat only when NotebookLM has finished answering the one before it, after a short pause you choose, so you can ask for a summary, a risk list, an FAQ and a table in one go and come back to all the answers. When the queue finishes, copy or download every prompt with its answer as one Markdown document.

### How to use it

1. Open a notebook in NotebookLM.
2. Click **Queue** in the NotebookTools ribbon, or **Prompts** → **Prompt queue**.
3. Add prompts: type one and press Enter, paste a list and click **Add each line**, or click **From my prompts** to pick saved prompts. Reorder or remove them before you start.
4. Choose the pause between prompts (3 to 30 seconds) and press **Start**. Keep the tab open while it runs.
5. Press **Pause** to stop after the current answer, or **Stop** to stop now. **Continue** picks up where it left off.
6. When it finishes, click **Copy answers** or **Download** to keep every prompt and answer together.

### Why it helps

Getting the most from a notebook usually takes several questions: a summary, then the risks, then a draft, then a table. Asking them one by one means waiting for each answer before typing the next. The queue does the waiting for you and keeps the answers together, so a set of prompts you use for every new notebook (a study routine, a research review, a launch brief) runs in one go.

### Built to be used fairly

You start every run and can see it the whole time. It runs only in the open notebook tab and never by itself after a reload, holds up to 25 prompts, pauses between them like a person would, never overwrites text you are typing in the chat box, and stops if NotebookLM says a usage limit has been reached. It sends the same prompts you would type yourself, within NotebookLM's own limits.

## Prompt queue: frequently asked questions

### Can NotebookLM run several prompts automatically?

Not on its own. With NotebookTools you add prompts to a queue and press Start; each one is sent when NotebookLM has finished the answer before it.

### How does it know an answer is finished?

It waits until NotebookLM's answer has stopped changing and the chat box is ready again, then pauses for the time you chose before sending the next prompt.

### Can I use my saved prompts?

Yes. Click From my prompts in the queue to add any prompt from your prompt library.

### Does it keep running if I close the tab?

No. The queue runs only while the notebook tab is open, and it never restarts by itself. Your list is saved for that notebook, so you can press Start again later.
