About NotebookTools

NotebookTools is a free Chrome extension built for people who use Google NotebookLM as a research hub. It adds import buttons on YouTube watch pages, X posts, and any webpage, plus a right-click action to send highlighted text straight into a notebook. No new account, no backend servers, and no paywall. For step-by-step workflows, see tutorials and import guides. Install from the Chrome Web Store and start importing in under two minutes.
