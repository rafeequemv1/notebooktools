NotebookLM source limits explained (2026)

Updated November 8, 2026 · 7 min read

Short answer

On the free plan you can add up to 50 sources to each notebook and create up to 100 notebooks. Each source can be up to 500,000 words or 200 MB. Paid Google AI plans raise the per-notebook limit: 100 sources on Google AI Plus, 300 on Google AI Pro and 500+ on Google AI Ultra. The same limits apply under the new Gemini Notebook name.

“This notebook has reached its source limit. Upgrade.” What to do

You see this message when a notebook already holds the maximum number of sources for your plan (50 on Free). NotebookLM will not accept new sources until you free a slot. You have four options:

  1. Delete sources you no longer need. Removing a source frees its slot immediately. Duplicates are the usual culprit: the same PDF or URL added twice uses two slots.
  2. Merge small sources. Paste ten short articles or notes into one Google Doc and add that instead. It counts as one source.
  3. Split the project. Move part of the material into a second notebook with a narrower topic. You have 100 notebooks on the free plan.
  4. Upgrade. Google AI Plus raises the cap to 100 sources per notebook, Google AI Pro to 300.

What counts as a source (and what does not)

Each of these is one source:

  • A single PDF, Word or text file upload
  • One web page URL
  • One YouTube video link
  • One Google Drive file (Docs, Slides, Sheets)
  • One block of pasted text
  • One audio file

A 300-page PDF uploaded as one file counts as one source, as long as it stays under 500,000 words and 200 MB. Ten short article URLs count as ten sources. Your chat messages, saved notes and Studio outputs (Audio Overviews, reports, slide decks) do not count toward the limit; only items in the Sources panel do.

How many files can you upload at once?

The upload dialog lets you select several files in one go. Each file still becomes its own source, so the real ceiling is the number of free slots left in the notebook. A notebook with 45 sources on the free plan can take 5 more, whether you add them one at a time or together. To add many web links or a whole YouTube playlist at once, use NotebookTools bulk import, which queues them and stops at the notebook's limit.

File size limits and processing

Each source can be up to 500,000 words or 200 MB, whichever comes first, on every plan. Very large scanned PDFs, long audio files or huge web pages may take longer to process or be cut off. If a source fails, split a large PDF into parts, compress scanned images, or paste only the sections you need as text.

Processing time grows with source size. A 90-minute YouTube lecture takes longer than a two-page article, so give new sources a moment before asking detailed questions.

Tips to work within NotebookLM limits

  • One notebook per topic. One per course, client or chapter beats one giant notebook, and gives sharper answers.
  • Add primary sources first. Papers, transcripts and canonical references before summaries of material you already have.
  • Audit monthly. Delete stale sources you no longer ask about.
  • Merge, do not multiply. Combine related short notes into one document.
  • Import efficiently. Use NotebookTools to add YouTube videos and web pages in one click. See the best ways to import content.

When to use multiple notebooks

If a project has a clear boundary (a semester, a product launch, a legal matter), give it its own notebook. The trade-off: NotebookLM answers from the sources within one notebook, so you cannot ask one chat to compare Notebook A with Notebook B. Split along topics that do not need cross-referencing, and keep a small "master" notebook for sources you use everywhere.

FAQ

How many sources can I add to NotebookLM?

Up to 50 sources per notebook on the free plan, across all file types and links. Google AI Plus allows 100, Google AI Pro 300 and Google AI Ultra 500+.

Does NotebookLM have a limit on notebooks?

Yes. The free plan allows up to 100 notebooks. Google AI Pro raises that to 500.

What is the NotebookLM file size limit?

Each source can be up to 500,000 words or 200 MB, on every plan.

What does “This notebook has reached its source limit” mean?

The notebook already holds the maximum number of sources for your plan (50 on Free). Delete or merge sources, move some into a new notebook, or upgrade to Google AI Plus (100) or Pro (300).

Is the Gemini Notebook source limit different?

No. Gemini Notebook is the new name for NotebookLM, and the limits are the same: 50 sources per notebook on Free, 100 on Google AI Plus, 300 on Pro and 500+ on Ultra.

Why did my upload fail?

Check that the file is under 200 MB and 500,000 words, that the format is supported, and that the notebook is not already full. Visit our support page if problems persist.
