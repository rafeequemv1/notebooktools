A notebook only helps if you ask it the right way. These twenty NotebookLM prompts are built for three jobs: get up to speed, push past surface-level notes, and turn sources into work you can use. Copy one, then follow up on the weak spots.

This list is part of the NotebookTools prompt cluster. Load the notebook first with papers, notes, or YouTube lectures. NotebookTools speeds up that import step.

How to get better answers

  • Stay in the sources — add “use only my uploaded materials” when you want tight grounding.
  • Name the output — bullets, table, quiz, or a one-page brief beats “tell me about this.”
  • Name the reader — beginner, exam candidate, or busy teammate changes the depth.
  • Iterate — ask NotebookLM to expand the weakest point instead of restarting.

Learn faster

Use these when you need orientation, notes you can review, or a quick check that you understood the material.

  1. 1. Ten-idea briefing

    Turn a long source into a short map of what actually matters.

    Prompt

    From my uploaded sources only, list the 10 ideas I should remember. For each: one sentence in plain English, why it matters, and one practical takeaway. Skip filler and repeated points.

  2. 2. Absolute-beginner walkthrough

    Use this when a paper or lecture assumes too much background.

    Prompt

    Teach this notebook as if I have never studied the topic. Use everyday analogies, define every technical term the first time it appears, and walk through the logic in short steps. End with three questions I can use to check my understanding.

  3. 3. Layered concept map

    Move from the obvious claims to what a careful reader would notice.

    Prompt

    Break these sources into four layers: (1) core concepts, (2) assumptions the authors do not spell out, (3) expert-level nuance, and (4) details most summaries skip. Keep each layer short and cite which source supports each point.

  4. 4. Structured study notes

    A clean outline you can reopen the night before a class or meeting.

    Prompt

    Rewrite this notebook as study notes. Use headings, short bullets, a definition for each key term, and one memorable example per section. Keep claims tied to the sources. Do not invent extra reading.

  5. 5. Active-recall cards

    Better than rereading — force a question/answer loop.

    Prompt

    Make 25 flashcards from these sources. Front: a precise question. Back: a short answer plus the source it came from. Cover definitions, cause and effect, and easy-to-confuse pairs. One card per line, formatted Question :: Answer.

  6. 6. Graded quiz

    Test yourself in chat, then ask NotebookLM to score the answers.

    Prompt

    Quiz me from these sources only. Start easy, then get harder. Ask one question at a time, wait for my answer, then grade it and explain what I missed. After ten questions, list the topics I should review.

  7. 7. Memory hooks

    When facts will not stick, ask for anchors you can reuse.

    Prompt

    For the most important ideas in this notebook, give me a mnemonic, a simple analogy, and a one-line memory hook. Prefer hooks I can say out loud. Note which source each idea comes from.

  8. 8. Five-minute teaching script

    If you can explain it, you understood it.

    Prompt

    Write a five-minute teaching script from these sources. Opening hook, three points I must hit, one example for each point, and a closing recap. Use spoken language, not essay prose. Stay inside the uploaded material.

Think deeper

Use these when you already know the basics and want argument, contrast, or a system you can reuse.

  1. 9. Agreement and conflict map

    See where sources line up — and where they do not.

    Prompt

    Compare every source in this notebook. Make three lists: where they agree, where they conflict, and what only one source contributes. For each conflict, state the disagreement in one sentence and note the evidence each side uses.

  2. 10. Missing-piece audit

    Find holes before you write or present.

    Prompt

    Read these sources as a skeptical reviewer. List unanswered questions, thin arguments, missing evidence, and research gaps. For each gap, say what kind of source would help (paper, dataset, expert talk, or primary document).

  3. 11. Two-expert debate

    Force both sides instead of a one-note summary.

    Prompt

    Take the main claim in these sources and run a debate between two experts. Give the strongest case for it, the strongest case against it, and a short referee note on which evidence is weakest. Do not invent studies that are not in the notebook.

  4. 12. Repeatable framework

    Turn scattered ideas into a checklist you can apply next time.

    Prompt

    Convert the useful ideas in this notebook into a practical framework or checklist I can reuse. Name each step, say what to look for, and add a warning for the most common mistake. Ground every step in the sources.

  5. 13. Source-only expert mode

    Keep a Q&A session from drifting into generic advice.

    Prompt

    Act as a specialist on these uploaded materials only. I will ask follow-up questions. Answer from the sources, cite which one you used, and say “not in my sources” when the notebook does not cover it. Do not fill gaps with general knowledge.

  6. 14. Original applications

    Use the notebook as raw material, not just a recap.

    Prompt

    Using only ideas present in these sources, propose 15 original applications, experiments, or project angles. For each: the idea in one line, which source inspired it, and why it is not just a restatement of the author’s conclusion.

Research smarter

Use these when the goal is output: a timeline, a brief, a syllabus, or a next-step plan.

  1. 15. Clean timeline

    Put events in order when sources jump around.

    Prompt

    Extract every dated event, milestone, or sequence from these sources and arrange them from earliest to latest. Include the date or period if given, a one-line description, and the source. Mark anything that is approximate or undated.

  2. 16. Cite-ready evidence

    Collect quotes and numbers before you write.

    Prompt

    Pull the strongest quotes, statistics, and pieces of evidence from this notebook. For each item: the quote or figure, why it is useful, and which source it came from. Prefer material I can cite in a paper or slide, not generic restatements.

  3. 17. Five-minute decision brief

    For someone who will not read the sources.

    Prompt

    Write a five-minute executive brief from these sources. Sections: situation, three strategic insights, implications, risks, and recommended actions. Keep it under 350 words and cite the source behind each insight.

  4. 18. Repurpose the research

    One notebook, several publishable drafts.

    Prompt

    From these sources, draft four short pieces: a LinkedIn post, an article outline, a six-post thread, and a newsletter blurb. Keep claims grounded in the notebook. Label anything that would need a fact-check before publishing.

  5. 19. Seven-day learning plan

    Turn the notebook into a short course instead of a pile of files.

    Prompt

    Turn this notebook into a 7-day learning plan. For each day: the goal, what to review from the sources, one exercise, and a checkpoint question. Keep the plan realistic for about 45 minutes a day.

  6. 20. Next-step action plan

    Leave the chat with a sequence, not just notes.

    Prompt

    Based only on these sources, give me a practical action plan: first three steps, what to prioritize this week, what can wait, and a deadline for each step. If the sources do not support a step, say so instead of inventing one.
