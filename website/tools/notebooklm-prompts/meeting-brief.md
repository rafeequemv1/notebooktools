# Brief from meeting notes: NotebookLM Chat prompt

> Turns transcripts and notes into decisions, owners and open questions. Replace the [blanks], then paste it in NotebookLM (Chat).

- Page: https://www.notebooktools.com/tools/notebooklm-prompts/meeting-brief
- Fill the blanks interactively: https://www.notebooktools.com/tools/notebooklm-prompts#meeting-brief
- Jobs: Work, Summarize
- Updated: 2026-11-22

## The prompt

```
Write a brief on [Project] for [Who it is for], based only on these meeting notes.

Sections: Decisions made (with dates), Action items (owner and due date), Open questions, Risks. Use bullet points. If an owner or date is missing, write "unassigned" or "no date" instead of guessing. Keep it under 300 words.
```

## Where to paste it

1. Open your notebook.
2. Tick the sources the prompt should use.
3. Paste the prompt into the chat box at the bottom and send.

## When to use it

After a series of meetings or calls, with transcripts or notes added as sources.

**Tip.** Name the people in the notes consistently (first names) so owners are matched correctly.

## Example, filled in

Write a brief on the Q3 website relaunch for my manager, based only on these meeting notes.

## FAQ

### Where do I paste a NotebookLM chat prompt?

Open your notebook. Tick the sources the prompt should use. Paste the prompt into the chat box at the bottom and send.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
