# Literature themes and gaps: NotebookLM Chat prompt

> Groups your papers into themes, shows where they disagree, and lists the open questions. Replace the [blanks], then paste it in NotebookLM (Chat).

- Page: https://www.notebooktools.com/tools/notebooklm-prompts/literature-themes
- Fill the blanks interactively: https://www.notebooktools.com/tools/notebooklm-prompts#literature-themes
- Jobs: Research
- Updated: 2026-11-22

## The prompt

```
My research question is: [Research question].

Group my sources into [Number of themes] themes. For each theme, give a two-sentence summary, the sources that support it, and any source that disagrees. Then list the questions my sources leave open, phrased so I could study them. End with the three sources I should read first and why.

Cite a source for every claim. If my sources do not cover something, say "not covered" instead of guessing.
```

## Where to paste it

1. Open your notebook.
2. Tick the sources the prompt should use.
3. Paste the prompt into the chat box at the bottom and send.

## When to use it

You have the papers for a review in one notebook and want structure before you start writing.

**Tip.** Works best with five or more papers; themes only appear across several sources.

## Example, filled in

```
My research question is: how sleep affects memory consolidation.

Group my sources into 3 to 5 themes. For each theme, give a two-sentence summary, the sources that support it, and any source that disagrees. Then list the questions my sources leave open, phrased so I could study them. End with the three sources I should read first and why.

Cite a source for every claim. If my sources do not cover something, say "not covered" instead of guessing.
```

## FAQ

### Where do I paste a NotebookLM chat prompt?

Open your notebook. Tick the sources the prompt should use. Paste the prompt into the chat box at the bottom and send.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
