# Summary in plain English: NotebookLM Chat prompt

> A short, jargon-free summary of the selected sources for a specific reader. Replace the [blanks], then paste it in NotebookLM (Chat).

- Page: https://www.notebooktools.com/tools/notebooklm-prompts/plain-summary
- Fill the blanks interactively: https://www.notebooktools.com/tools/notebooklm-prompts#plain-summary
- Jobs: Summarize
- Updated: 2026-11-21

## The prompt

```
Summarize the selected sources for [Reader] in about [Length].

Lead with the single most important takeaway. Replace jargon with everyday words, or define it in brackets the first time. Add one concrete example. End with "What this means for you:" and one sentence.
```

## Where to paste it

1. Open your notebook.
2. Tick the sources the prompt should use.
3. Paste the prompt into the chat box at the bottom and send.

## When to use it

When you need to explain a dense paper, report or policy to someone outside the field.

**Tip.** Select one source at a time for a summary of that source only.

## Example, filled in

```
Summarize the selected sources for a parent with no science background in about 150 words.

Lead with the single most important takeaway. Replace jargon with everyday words, or define it in brackets the first time. Add one concrete example. End with "What this means for you:" and one sentence.
```

## FAQ

### Where do I paste a NotebookLM chat prompt?

Open your notebook. Tick the sources the prompt should use. Paste the prompt into the chat box at the bottom and send.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
