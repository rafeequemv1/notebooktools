# Lecture deck: NotebookLM Slide deck prompt

> A teaching deck with one idea per slide, examples and a check-in question. Replace the [blanks], then paste it in NotebookLM (Slide deck).

- Page: https://www.notebooktools.com/tools/notebooklm-prompts/slides-lecture
- Fill the blanks interactively: https://www.notebooktools.com/tools/notebooklm-prompts#slides-lecture
- Jobs: Teach
- Updated: 2026-11-21

## The prompt

```
Create a lecture deck on [Lecture topic] for [Students]. One idea per slide, with a clear headline that states the point. Add an example or image idea for each concept. Every 5 slides, include a check-in question for the class. End with a summary slide and three discussion questions.
```

## Where to paste it

1. Open Studio on the right.
2. Click the pencil on Slide deck (Customise).
3. Paste the prompt into "Describe the slide deck" and generate.

## When to use it

Turning a chapter or set of readings into slides for a class.

**Tip.** Add a style from the gallery below the prompt for a consistent look.

## Example, filled in

## FAQ

### Where do I paste a NotebookLM slide deck prompt?

Open Studio on the right. Click the pencil on Slide deck (Customise). Paste the prompt into "Describe the slide deck" and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
