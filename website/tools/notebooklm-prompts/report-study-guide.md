## The prompt

```
Write a study guide for [Unit or topic]. Sections: key terms with one-line definitions; the main ideas in a logical order; two worked examples; common mistakes; and [Practice questions] practice questions with answers in a separate section at the end. Use only the sources and cite them.
```

## Where to paste it

1. Open Studio on the right.
2. Choose Reports, then Create your own.
3. Paste the prompt and generate.

## When to use it

Building revision material for a unit or course.

**Tip.** Generate it again later with a different set of sources ticked for each sub-topic.

## Example, filled in

```
Write a study guide for organic chemistry: reaction mechanisms. Sections: key terms with one-line definitions; the main ideas in a logical order; two worked examples; common mistakes; and 10 practice questions with answers in a separate section at the end. Use only the sources and cite them.
```

## FAQ

### Where do I paste a NotebookLM report prompt?

Open Studio on the right. Choose Reports, then Create your own. Paste the prompt and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
