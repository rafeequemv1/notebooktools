# Two-sided debate: NotebookLM Audio Overview prompt

> The two hosts take opposite sides on a question your sources disagree about. Replace the [blanks], then paste it in NotebookLM (Audio Overview).

- Page: https://www.notebooktools.com/tools/notebooklm-prompts/audio-debate
- Fill the blanks interactively: https://www.notebooktools.com/tools/notebooklm-prompts#audio-debate
- Jobs: Research, Study
- Updated: 2026-11-21

## The prompt

```
Make this a debate on: [Debate question]. One host argues for, the other against, each using only evidence from the sources. Keep it respectful and specific, with numbers and examples where the sources give them. Finish with where the evidence is strongest on each side and what is still unknown.
```

## Where to paste it

1. Open Studio on the right.
2. Click the pencil on Audio Overview (Customise).
3. Paste the prompt into the focus box and generate.

## When to use it

When your sources contain competing views and you want to hear both argued well.

**Tip.** Include sources from both sides, or the debate will be lopsided.

## Example, filled in

```
Make this a debate on: Should cities ban cars from their centres?. One host argues for, the other against, each using only evidence from the sources. Keep it respectful and specific, with numbers and examples where the sources give them. Finish with where the evidence is strongest on each side and what is still unknown.
```

## FAQ

### Where do I paste a NotebookLM audio overview prompt?

Open Studio on the right. Click the pencil on Audio Overview (Customise). Paste the prompt into the focus box and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
