# FAQ document: NotebookLM Report prompt

> Turns long documentation into the questions people actually ask, answered. Replace the [blanks], then paste it in NotebookLM (Report).

- Page: https://www.notebooktools.com/tools/notebooklm-prompts/report-faq
- Fill the blanks interactively: https://www.notebooktools.com/tools/notebooklm-prompts#report-faq
- Jobs: Work, Write
- Updated: 2026-11-22

## The prompt

```
Write an FAQ for [Who will read it] with [Number of questions] questions, based only on the sources. Choose the questions a newcomer would really ask, in the order they would ask them. Answer each in 2 to 4 sentences with a citation. Add a final question: "Where do I go if my question isn't here?"
```

## Where to paste it

1. Open Studio on the right.
2. Choose Reports, then Create your own.
3. Paste the prompt and generate.

## When to use it

Writing a help page, onboarding guide or policy FAQ from long documents.

**Tip.** Paste a few real questions from colleagues into the focus to steer it.

## Example, filled in

```
Write an FAQ for new employees with 12 questions, based only on the sources. Choose the questions a newcomer would really ask, in the order they would ask them. Answer each in 2 to 4 sentences with a citation. Add a final question: "Where do I go if my question isn't here?"
```

## FAQ

### Where do I paste a NotebookLM report prompt?

Open Studio on the right. Choose Reports, then Create your own. Paste the prompt and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
