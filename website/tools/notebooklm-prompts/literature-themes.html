Where to paste it

  1. Open your notebook.
  2. Tick the sources the prompt should use.
  3. Paste the prompt into the chat box at the bottom and send. Replace the [blanks] first.

When to use it

You have the papers for a review in one notebook and want structure before you start writing.

Tip. Works best with five or more papers; themes only appear across several sources.

Example, filled in

My research question is: how sleep affects memory consolidation.

Group my sources into 3 to 5 themes. For each theme, give a two-sentence summary, the sources that support it, and any source that disagrees. Then list the questions my sources leave open, phrased so I could study them. End with the three sources I should read first and why.

Cite a source for every claim. If my sources do not cover something, say "not covered" instead of guessing.

What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.
