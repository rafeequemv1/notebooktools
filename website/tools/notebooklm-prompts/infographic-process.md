# Process infographic: NotebookLM Infographic prompt

> A step-by-step visual of how something works. Replace the [blanks], then paste it in NotebookLM (Infographic).

## The prompt

```
Make an infographic of [Process] as numbered steps from start to finish. Use a short label and one line of explanation per step, with a simple icon for each. Highlight the step where things most often go wrong.
```

## Where to paste it

1. Open Studio on the right.
2. Click the pencil on Infographic (Customise).
3. Paste the prompt into the description box and generate.

## When to use it

Turning a procedure, method or natural process into one image.

**Tip.** Ask for portrait orientation if it is for a phone or a printed handout.

## Example, filled in

```
Make an infographic of how a loan application is approved as numbered steps from start to finish. Use a short label and one line of explanation per step, with a simple icon for each. Highlight the step where things most often go wrong.
```

## FAQ

### Where do I paste a NotebookLM infographic prompt?

Open Studio on the right. Click the pencil on Infographic (Customise). Paste the prompt into the description box and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
