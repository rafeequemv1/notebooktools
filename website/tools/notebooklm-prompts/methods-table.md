# Methods comparison table: NotebookLM Chat prompt

> A side-by-side table of how each study was done and what it found. Replace the [blanks], then paste it in NotebookLM (Chat).

- Page: https://www.notebooktools.com/tools/notebooklm-prompts/methods-table
- Fill the blanks interactively: https://www.notebooktools.com/tools/notebooklm-prompts#methods-table
- Jobs: Research
- Updated: 2026-11-22

## The prompt

```
Make a table with one row per source and these columns: Source | Research question | Method | Sample | Key finding | Limitation | [Extra column].

Keep each cell under 20 words. Write "not stated" when a source does not give the information. Under the table, add three sentences on what the methods have in common and where they differ.
```

## Where to paste it

1. Open your notebook.
2. Tick the sources the prompt should use.
3. Paste the prompt into the chat box at the bottom and send.

## When to use it

When you need to compare study designs, samples and findings at a glance.

**Tip.** Copy the table into a sheet with the extension's chat export to keep the formatting.

## FAQ

### Where do I paste a NotebookLM chat prompt?

Open your notebook. Tick the sources the prompt should use. Paste the prompt into the chat box at the bottom and send.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
