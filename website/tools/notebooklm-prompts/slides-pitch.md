# Pitch deck: NotebookLM Slide deck prompt

> Problem, solution, evidence and ask, built from your research. Replace the [blanks], then paste it in NotebookLM (Slide deck).

## The prompt

```
Create a pitch deck for [What you are pitching] aimed at [Audience]. Slides: the problem (with a number from the sources), who has it, the solution, why now, evidence and traction, competition, the plan, and the ask: [Your ask]. Headlines should state the point, not the topic. Keep text short.
```

## Where to paste it

1. Open Studio on the right.
2. Click the pencil on Slide deck (Customise).
3. Paste the prompt into "Describe the slide deck" and generate.

## When to use it

Pitching an idea, product or project using market research and notes in the notebook.

**Tip.** Use the "Presenter slides" format if you will speak over the deck.

## Example, filled in

```
Create a pitch deck for a tutoring app for nursing students aimed at seed investors. Slides: the problem (with a number from the sources), who has it, the solution, why now, evidence and traction, competition, the plan, and the ask: $250k to build the first version. Headlines should state the point, not the topic. Keep text short.
```

## FAQ

### Where do I paste a NotebookLM slide deck prompt?

Open Studio on the right. Click the pencil on Slide deck (Customise). Paste the prompt into "Describe the slide deck" and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
