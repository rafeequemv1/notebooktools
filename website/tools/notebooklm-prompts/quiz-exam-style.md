# Exam-style quiz: NotebookLM Quiz prompt

> A quiz that mirrors your exam format, from easy to hard. Replace the [blanks], then paste it in NotebookLM (Quiz).

## The prompt

```
Quiz me on [Topic] with questions in the style of [Exam style]. Go from easy to hard. Use plausible wrong answers that reflect common misunderstandings. After each answer, explain why it is right.
```

## Where to paste it

1. Open Studio on the right.
2. Click the pencil on Quiz (Customise).
3. Paste the prompt into the topic box and generate.

## When to use it

A few days before an exam, to find what you don't know yet.

**Tip.** Redo the quiz after studying the explanations of the ones you got wrong.

## Example, filled in

```
Quiz me on statistics: hypothesis testing with questions in the style of applied problems, not definitions. Go from easy to hard. Use plausible wrong answers that reflect common misunderstandings. After each answer, explain why it is right.
```

## FAQ

### Where do I paste a NotebookLM quiz prompt?

Open Studio on the right. Click the pencil on Quiz (Customise). Paste the prompt into the topic box and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
