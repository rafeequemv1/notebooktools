# Beginner-friendly explainer: NotebookLM Audio Overview prompt

> Explains a technical topic to someone hearing about it for the first time. Replace the [blanks], then paste it in NotebookLM (Audio Overview).

## The prompt

```
Explain [Topic] to a curious listener with no background. Use analogies from everyday life, avoid jargon or explain it immediately, and build from the basics up. Include one surprising fact from the sources. End by saying what to read or watch next from the sources.
```

## Where to paste it

1. Open Studio on the right.
2. Click the pencil on Audio Overview (Customise).
3. Paste the prompt into the focus box and generate.

## When to use it

When the sources are technical and the listener is new to the field.

**Tip.** Pair it with the Video Overview prompt below for a visual version.

## FAQ

### Where do I paste a NotebookLM audio overview prompt?

Open Studio on the right. Click the pencil on Audio Overview (Customise). Paste the prompt into the focus box and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
