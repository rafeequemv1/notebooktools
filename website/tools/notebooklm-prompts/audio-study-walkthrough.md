# Study walkthrough podcast: NotebookLM Audio Overview prompt

> An Audio Overview that teaches the material in exam order, with recap questions. Replace the [blanks], then paste it in NotebookLM (Audio Overview).

## The prompt

```
Teach [Course or topic] as a study session for a student preparing for an exam. Go through the topics in a logical order, define every key term the first time it appears, and use one example per idea. Every few minutes, pause to ask the listener a recap question and then answer it. End with the five things to remember.
```

## Where to paste it

1. Open Studio on the right.
2. Click the pencil on Audio Overview (Customise).
3. Paste the prompt into the focus box and generate.

## When to use it

Revising on the go: commuting, walking or at the gym.

**Tip.** Generate a short version first to check the focus, then a longer one.

## FAQ

### Where do I paste a NotebookLM audio overview prompt?

Open Studio on the right. Click the pencil on Audio Overview (Customise). Paste the prompt into the focus box and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
