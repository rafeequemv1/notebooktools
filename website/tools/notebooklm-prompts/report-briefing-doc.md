# Decision briefing: NotebookLM Report prompt

> A one-page briefing: situation, findings, risks and a recommendation. Replace the [blanks], then paste it in NotebookLM (Report).

- Page: https://www.notebooktools.com/tools/notebooklm-prompts/report-briefing-doc
- Fill the blanks interactively: https://www.notebooktools.com/tools/notebooklm-prompts#report-briefing-doc
- Jobs: Work
- Updated: 2026-11-21

## The prompt

```
Write a one-page briefing for [Reader] on [Decision]. Sections: Situation; Options (a table comparing them on cost, risk and effort); Key findings with citations; Risks; Recommendation with the reason in one sentence. Max 500 words.
```

## Where to paste it

1. Open Studio on the right.
2. Choose Reports, then Create your own.
3. Paste the prompt and generate.

## When to use it

When someone needs to make a decision from a pile of documents.

**Tip.** Add each vendor's pricing page as a source for a fair comparison.

## Example, filled in

```
Write a one-page briefing for the leadership team on which CRM to adopt. Sections: Situation; Options (a table comparing them on cost, risk and effort); Key findings with citations; Risks; Recommendation with the reason in one sentence. Max 500 words.
```

## FAQ

### Where do I paste a NotebookLM report prompt?

Open Studio on the right. Choose Reports, then Create your own. Paste the prompt and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
