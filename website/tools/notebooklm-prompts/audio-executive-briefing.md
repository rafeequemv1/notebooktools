# Executive briefing: NotebookLM Audio Overview prompt

> A short, decision-focused Audio Overview for someone with ten minutes. Replace the [blanks], then paste it in NotebookLM (Audio Overview).

- Page: https://www.notebooktools.com/tools/notebooklm-prompts/audio-executive-briefing

## The prompt

```
Brief [Listener] who must decide [Decision they face]. Skip background they already know. Cover the three facts that matter most for the decision, the main risk, the main upside and what is still uncertain. Keep it short and concrete, and end with a clear recommendation the sources support.
```

## Where to paste it

1. Open Studio on the right.
2. Click the pencil on Audio Overview (Customise).
3. Paste the prompt into the focus box and generate.

## When to use it

Briefing a busy stakeholder on a report, market scan or set of documents.

**Tip.** Choose the shortest length in the Audio Overview settings for a true 5-to-10-minute briefing.

## Example, filled in

```
Brief a CFO who must decide whether to expand into Germany. Skip background they already know. Cover the three facts that matter most for the decision, the main risk, the main upside and what is still uncertain. Keep it short and concrete, and end with a clear recommendation the sources support.
```

## FAQ

### Where do I paste a NotebookLM audio overview prompt?

Open Studio on the right. Click the pencil on Audio Overview (Customise). Paste the prompt into the focus box and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
