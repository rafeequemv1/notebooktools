# Exam cram sheet: NotebookLM Chat prompt

> One page that covers what the exam will ask, built from your own lectures and readings. Replace the [blanks], then paste it in NotebookLM (Chat).

## The prompt

```
Make a one-page cram sheet for [Course or topic]. The exam is [Exam format].

1. List the 10 ideas that come up most often across my sources, each with a one-line definition.
2. Add the formulas, dates or names I must remember, in a compact table.
3. Write 5 likely exam questions and the key points a strong answer would hit.
4. Flag 3 common mistakes students make on this material.

Use only my sources and cite them. If something is not in the sources, leave it out.
```

## Where to paste it

1. Open your notebook.
2. Tick the sources the prompt should use.
3. Paste the prompt into the chat box at the bottom and send.

## When to use it

The week before an exam, once all the lecture slides and readings for the course are in one notebook.

**Tip.** Untick sources that are not part of the exam, such as last year's notes, before you send it.

## FAQ

### Where do I paste a NotebookLM chat prompt?

Open your notebook. Tick the sources the prompt should use. Paste the prompt into the chat box at the bottom and send.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
