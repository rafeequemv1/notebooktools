# Research findings deck: NotebookLM Slide deck prompt

> Presents what the sources found, how sure we are, and what to do next. Replace the [blanks], then paste it in NotebookLM (Slide deck).

- Page: https://www.notebooktools.com/tools/notebooklm-prompts/slides-research-summary
- Fill the blanks interactively: https://www.notebooktools.com/tools/notebooklm-prompts#slides-research-summary
- Jobs: Research
- Updated: 2026-11-22

## The prompt

```
Create a deck presenting what my sources say about: [Research question]. Start with a one-slide answer. Then one slide per key finding with the supporting sources, one slide on where sources disagree, one on limitations, and a final slide with recommended next steps. Put source names on each slide.
```

## Where to paste it

1. Open Studio on the right.
2. Click the pencil on Slide deck (Customise).
3. Paste the prompt into "Describe the slide deck" and generate.

## When to use it

Sharing a literature review or research results with a team or supervisor.

**Tip.** Works best when every source is a paper or report, not notes.

## Example, filled in

```
Create a deck presenting what my sources say about: Does remote work affect productivity?. Start with a one-slide answer. Then one slide per key finding with the supporting sources, one slide on where sources disagree, one on limitations, and a final slide with recommended next steps. Put source names on each slide.
```

## FAQ

### Where do I paste a NotebookLM slide deck prompt?

Open Studio on the right. Click the pencil on Slide deck (Customise). Paste the prompt into "Describe the slide deck" and generate.

### What do the [brackets] mean?

They are blanks. Replace each one with your own words before you paste the prompt, or fill them in the prompt library, which shows them as fields inside the text.

### Does this prompt work in Gemini Notebook?

Yes. Gemini Notebook is the new name for NotebookLM, and the chat and Studio work the same way.
